# 需求富文本与图片实现计划

**目标：** 新建和查看需求时支持格式化文字、上传/粘贴图片；旧数据自动迁移，备份保留完整图文。

**实现范围：** 使用 Tiptap 存储结构化文档，保留纯文本备注以兼容旧数据。图片压缩后内嵌文档，避免跨设备链接失效。项目、需求统一存入 IndexedDB 的单条快照，更新和导入在事务完成后才更新界面。

1. 新增富文本文档校验与图片压缩工具，拒绝外部图片、脚本和不支持的节点。
2. 新增 IndexedDB 存储，首次运行迁移 localStorage，已有数据库优先，迁移失败保留旧数据。
3. 新建/编辑需求接入富文本编辑器，新增图文详情视图；支持粗体、标题、列表、代码、图片上传和截图粘贴。
4. 备份升级为 v2，携带内嵌图片，兼容 v1 纯文字备份；文件上限调整为 50 MB。
5. 验证旧数据迁移、图文保存/重开/导入导出、错误文件和事务失败；构建、浏览器和 Electron 验证通过后以 `feat: 中文说明` 提交并推送。
