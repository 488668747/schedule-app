适用于 **Apple 芯片（M1 / M2 / M3 / M4 及后续型号）Mac**。

### 下载与安装

1. 展开本页底部的 **Assets**。
2. 下载名称以 `mac-arm64.dmg` 结尾的文件。
3. 双击 DMG，把“节奏”拖到 **Applications（应用程序）**。
4. 从启动台或应用程序文件夹打开“节奏”。安装后无需启动开发服务。

当前版本使用本地临时签名，尚未进行 Apple 开发者签名和公证。如首次打开被系统拦截，请前往 **系统设置 → 隐私与安全性 → 仍要打开**。

### 包含功能

- 项目与需求管理、月度排期时间轴、状态和优先级筛选。
- 图文需求描述，支持图片上传、截图粘贴、富文本格式和完整详情查看。
- 本地保存，支持包含图片的 JSON 备份导入与导出。

### 迁移与更新

- 浏览器或早期开发版的数据需要先导出备份，再在安装版中导入；导入会覆盖当前数据。
- 更新前建议导出备份，退出应用后用新版 `.app` 覆盖旧版，正常覆盖安装会保留独立用户数据目录。
- 当前版本为手动更新，仅提供 Apple 芯片 Mac 安装包。

`SHA256SUMS.txt` 是安装包的校验文件。`Source code` 是源码压缩包，安装应用请选择 `.dmg`。
